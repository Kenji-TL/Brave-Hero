# Fotos do site

Salve as fotos aqui com **exatamente** esses nomes:

| Arquivo                  | Onde aparece                  |
|--------------------------|-------------------------------|
| `espaco-kids.jpg`        | Seção "Espaço kids"           |
| `festa-aniversario.jpg`  | Seção "Aniversário de herói"  |

Enquanto o arquivo não existir, o site mostra o painel em quadrinho no lugar. Não precisa mexer no HTML.

## Formato

- JPG, **vertical (4:5)** — ex.: 1080×1350. Foto horizontal também funciona, mas o site corta as laterais
- Até ~400 KB (comprime no squoosh.app se precisar)
- Pegue o arquivo original com o cliente, não baixe do Instagram (perde qualidade)
- Se aparecer criança, só com autorização dos pais
